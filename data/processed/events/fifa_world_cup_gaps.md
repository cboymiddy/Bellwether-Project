# fifa_world_cup gaps and disagreements

- Britannica (https://www.britannica.com/sports/World-Cup-football) returned a Cloudflare challenge; not used. fifa.com was not used (no usable static content was captured); the second source is RSSSF.
- Final dates: Wikipedia = date of the last match box on each edition page; RSSSF = date under its 'Final' heading (1950: decisive final-pool match, since no final was played).
- 2030: listed on the Wikipedia main table with host 'Morocco Portugal Spain [ n 3 ]' and no champion (TBA); not yet held per that page, excluded from the all-years table.
- 2034: listed on the Wikipedia main table with host 'Saudi Arabia' and no champion (TBA); not yet held per that page, excluded from the all-years table.
