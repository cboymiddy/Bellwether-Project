# nhl_stanley_cup gaps and cross-check log

- 1900-1916: no independent non-Wikipedia source reachable (Britannica 403, hockeydb 404, NHL records API has no pre-1917 data, Hockey-Reference has no pre-1918 pages). Cross-checked only between three Wikipedia articles (champions list, challenge-games list, per-year page) - NOT independent of each other.
- Hockey-Reference's 'Final' row for 1918-1926 is the NHL championship series, not the Cup final (e.g. 1924: Canadiens-Senators vs Cup final Canadiens-Calgary Tigers); only the winner is compared for those years.
- Completed dates are single-sourced from Wikipedia (game tables; challenge-games list for 1900-1912) and checked against the infobox 'Dates' line / champions-list date string; no second source for dates.
- 1960: the Wikipedia page has only 3 of 4 game tables; completed_date taken from the infobox 'Dates' line 'April 7–14, 1960' (1960-04-14) - single source, no second source for the last game date
